## 薪连薪合规助手

**Skill ID：** `xinlianxin-helper`

薪连薪合规助手是一款面向企业、平台、园区及生态服务商的 AI Agent Skill，
用于灵活用工与平台经济场景的初步合规信息整理、资料与证据缺口检查、
平台涉税关注点梳理及风险提示。
