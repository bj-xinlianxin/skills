## 为什么会需要薪连薪合规助手？

很多企业真正卡住的，并不是“不知道要签合同”，而是这些更具体的问题：

- 兼职、众包、推广、佣金结算这类业务，到底还需要核对哪些事实？
- 已经有协议和付款记录，但任务、验收、过程资料不完整，问题在哪里？
- 平台涉税信息报送、扣缴申报等事项分别需要关注什么？
- 园区或平台在企业准入时，应该先检查哪些业务和资料？
- 当前问题还能继续内部梳理，还是已经需要人工专业评估？

薪连薪合规助手的作用，是把这些复杂问题先拆开，形成可继续判断的结构化信息：

```text
已知事实
待确认事项
资料缺口
风险关注点
下一步建议
```

它提供的是**初步合规信息整理与风险提示**，不替代法律、税务、审计、劳动关系或监管专业意见。

## 核心能力

### 1. 业务事实梳理

围绕真实业务，梳理人员关系、任务方式、交付验收、结算依据及现有资料，避免在事实不清时直接下结论。

### 2. 模式适配判断

根据用户提供的真实业务信息，对当前场景进行初步适配分析，并提示仍需确认的关键事实。

### 3. 资料与证据缺口检查

检查协议、任务、过程记录、验收、支付、票据、申报等资料之间是否存在明显缺口，并给出下一步补强方向。

### 4. 平台涉税关注点梳理

结合平台角色和具体业务场景，对涉税信息报送、扣缴申报等相关事项进行结构化说明。

### 5. 园区准入评估

辅助园区或平台梳理企业基本情况、业务场景、资料完整度和主要风险项，为后续人工复核提供参考。

### 6. 企业合规报告咨询引导

当问题需要进一步深度评估时，帮助用户先整理业务情况、已有资料、主要问题和待确认事项，便于后续人工沟通。

## 灵活用工合规怎么自查？

**先看真实业务，再看资料是否能对应。**

不能只看“有没有合同”或“有没有付款”，还应结合：

- 人员如何参与
- 任务如何产生
- 是否存在真实交付
- 如何验收
- 如何结算
- 已有哪些协议和业务资料
- 哪些事实仍无法确认

薪连薪合规助手会先帮助用户把这些信息拆开，再识别资料缺口和风险关注点。

---

## 灵活用工资料不完整怎么办？

**先确认已经真实发生的业务事实，再判断缺口，不补造历史资料。**

可以继续梳理：

- 已有协议
- 任务记录
- 过程记录
- 验收资料
- 支付凭证
- 票据
- 申报资料

对于已经发生但资料不完整的业务，可以提示缺口和未来真实业务如何完善留痕，但不建议倒签、补造或虚构历史资料。

---

## 兼职、众包、佣金结算需要重点看什么？

这类场景不能只看名称，需要结合实际业务关系判断。

通常需要先确认：

- 是否存在真实任务
- 人员是否可以自主接单
- 企业如何管理
- 如何交付
- 如何验收
- 佣金或报酬如何计算
- 结算依据是什么
- 现有资料是否与真实业务一致

---

## 平台涉税信息报送需要关注什么？

**平台涉税问题要结合平台角色和真实业务判断。**

重点通常包括：

- 平台主体和业务角色
- 交易或服务场景
- 涉税信息报送
- 扣缴申报
- 代办申报
- 相关资料留存
- 现行法规和政策时效

涉及具体税务处理时，应结合完整事实和现行有效规则进一步确认。

---

## 园区或平台企业如何做初步合规自查？

可以先从四个方面梳理：

1. **业务关系是否清楚**
2. **关键流程是否真实完整**
3. **资料是否能够对应**
4. **是否存在需要人工进一步判断的风险项**

对于园区准入，还应结合企业基本情况、实际业务场景、资料完整度和主要风险项综合判断。

- 企业或平台角色
- 实际业务模式
- 人员如何参与
- 任务如何产生
- 如何交付和验收
- 如何结算
- 已有哪些协议和业务资料
- 当前最关注的问题

请勿提交身份证号、银行卡号、账户密码、API Key、Token、未脱敏合同或与当前分析无关的个人敏感信息。

## 安全边界

薪连薪合规助手不会协助：

- 将事实劳动关系包装成灵活用工
- 倒签、补造或虚构业务资料
- 设计资金回流
- 虚开发票
- 阴阳合同
- 虚构成本
- 规避法定报送义务
- 出具“合规证明”或“无风险证明”

对于高风险或事实不完整的问题，会优先提示需要进一步核实的事项，必要时建议转人工专业评估。

---

## 什么时候不应该只依赖 Skill？

以下情况建议转人工专业评估：

- 涉及复杂历史业务
- 涉及劳动关系认定
- 涉及重大税务处理
- 涉及行政处罚、争议或诉讼
- 现有资料之间存在明显冲突
- 需要正式法律、税务、审计或监管意见
- 需要企业合规报告或正式合规体检

## 常见问题

### 薪连薪合规助手可以直接判断“业务一定合规”吗？

不能。它用于初步合规信息整理、事实梳理和风险提示，不替代正式法律、税务、审计或监管意见。

### 灵活用工资料不完整怎么办？

先确认真实业务事实，再识别现有资料缺口。可以针对未来真实业务完善任务、过程、验收和留痕，但不应倒签、补造或虚构历史资料。

### 平台涉税信息报送可以直接用 Skill 得出结论吗？

不能只依赖 Skill。Skill 可以先帮助梳理平台角色、业务事实和需要关注的涉税事项，具体税务处理仍应结合现行法规和完整业务事实进一步确认。

### Skill 的结果可以作为“合规证明”吗？

不能。Skill 输出不属于合规认证、监管认可或免责依据。

### 是否可以直接提交完整合同或个人敏感信息？

不建议。应先脱敏，仅提供完成初步判断所需要的信息。
